## 设计说明

- 鲸鱼轮廓取自 DeepSeek 的蓝鲸标识，作为**非官方、非商业的致敬**。
- 身侧是粉色奶嘴（星星按钮 + 紫色拉环），嘴边是拨浪鼓（奶油鼓面 + 红色鼓身 + 木柄 + 双侧珠串），按参考插画重绘，线宽和配色与鲸鱼统一。
- 艺术字 “miniDeepSeek” 使用 Fredoka（SemiBold），口号
  “Train your own baby DeepSeek” 使用 DM Serif Display Italic。
- 字体只用于生成路径，不随仓库分发；两种字体均为 SIL Open Font License 1.1。
- 背景为暖白色卡片 + 细点阵，文字带轻微深蓝投影，整体参考
  [MiniMind](https://github.com/jingyaogong/minimind) 的轻量手绘风格。
