# 外部语料（download/）— 145M 预训练 + code

> 对应计划：`doc/data_plan_145m.md` §3.2（预训练混料）、§4（code SFT/GRPO）、§8（评测边界）。
> 这里只放**原始语料**，不做 tokenize、不做格式转换；处理产物仍走 `data/processed/`。
>
> **整个 `download/` 目录都不进 git**（`.gitignore` 已忽略），数据只在本地/服务器；
> 本文件是它的说明。每个文件的 bytes + sha256 + 上游 revision 记录在
> `download/manifest.json`。

## 2. 预训练（`download/pretrain/`）

| 数据集 | 许可 | 取了什么 | 体积 | 行数 | 过滤后可用 | 6400 词表 token |
|---|---|---|---|---|---|---|
| `HuggingFaceFW/fineweb-edu` | ODC-By | `sample/10BT/000–003` 4 shards | 8.61 GB | 2,916,000 | `int_score≥4` → 379,080（13.0%） | **641M** |
| `opencsg/chinese-fineweb-edu` | Apache-2.0 | `map/00022`（MAP-CC slice） | 2.60 GB | 300,000 | 全保留 | **1,233M** |
| `codeparrot/codeparrot-clean` | per-file（需白名单） | `file-000…001–016` 16 shards | 3.92 GB | 1,600,000 | ≤200 行 + permissive + 非自动生成 → 33.9% | **~750M**（≤60 行则 152M） |
| `HuggingFaceTB/smollm-corpus` | ODC-By | `cosmopedia-v2/train-00000–00001` | 2.35 GB | 752,578 | 全保留 | **902M** |
| `HuggingFaceTB/finemath` | ODC-By | `finemath-4plus/train-00000–00001` | 0.57 GB | 209,360 | 全保留（已 int_score≥4） | **419M** |

**过滤口径**（计划 §3.3）：预训练代码按 `≤200 行 / ≤8KB / alpha_frac≥0.3 / permissive
license / autogenerated=False` 统计；计划 §1.1 的 `≤60 行 / ≤400 token` 是 SFT 样本口径，
两者不要混用。fineweb-edu 的 `int_score` 实测分布：3 分占 87%，4 分 12.9%，5 分 0.1%。

## 7. 复现

```bash
cd miniDeepSeek
# 只下缺的文件；已存在则跳过，断点续传
.venv/bin/python scripts/fetch_external_data.py --jobs 4
# 只补 code / 只补 pretrain
.venv/bin/python scripts/fetch_external_data.py --only code
.venv/bin/python scripts/fetch_external_data.py --dry-run   # 看清单
```

脚本要点：

- `HF_HOME` 默认 `download/.hf_home`；`HF_HUB_DISABLE_XET=1`（本网络 xet 会 SSL EOF）；
- 外层 8 次重试 + 指数退避，hf 自身还有 5 次重试；
- 结束后写 `download/manifest.json`（sha256 可用 `shasum -a 256` 复核）。

校验脚本（本次实际跑的）：

```bash
# 行数 / 抽样 token / 字段
.venv/bin/python /tmp/verify_download.py --root download --tokenizer ../minimind/model/tokenizer.json
```

## 8. 已知问题与偏离

1. **`Salesforce/xlam-function-calling-60k` 未下载**：仓库已 gated，匿名 401。tool 预训练文本
   改用 ToolACE + glaive + 本地 `data/sft_tool.jsonl` 的 `tools` 字段扁平化；如需 xLAM，
   登录 HF、接受条款后把条目加回脚本即可。
2. **`opencsg/chinese-fineweb-edu` v1 已 deprecated**，官方推荐
   `opencsg/Fineweb-Edu-Chinese-V2.1`（2.4 TB，按分数分子集）。这里按计划用 v1 的 MAP-CC slice，
   小模型够用；将来要换 v2.1，取 `4_5` 子集若干小文件即可。
3. **`codeparrot-clean` 许可混杂**：抽样中 permissive 约 55%，GPL/AGPL/LGPL 约 32%。
   预处理必须按 `license` 白名单 + `autogenerated=False` 过滤；`≤200 行` 口径下通过率 33.9%。
4. **两个数据集没有 license 声明**：`python_code_instructions_18k_alpaca`（alpaca 派生）和
   `open-r1/verifiable-coding-problems`。进正式训练前要确认上游许可，或只做评测/内部研究用。
5. **TACO 只取了 train 4/9 shard**：EASY 3,940 已够 1–2k GRPO 池；要全量可把 `_files(...4...)`
   改回 9 重跑。TACO 的 `.arrow` 是 Arrow **stream**（不是随机访问 file 格式），读取用
   `pyarrow.ipc.open_stream`。
6. **finemath 偏多**：419M vs 计划 60M，暂时留着，混料时按权重截断即可。
